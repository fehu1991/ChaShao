## 1. 這個工具是什麼

### 1.1 定位

叉燒 ChaShao 是校園性平業務的**程序追蹤與文件管理工具**。它幫承辦人做三件事：

1. **不漏掉法定期限**——依案件實際情形自動建立該有的程序節點，並倒數每個法定死線。
2. **留下完整程序紀錄**——每個節點該附什麼文件、通知送達給了誰、什麼時候送到，都有固定欄位可登錄。
3. **產出可交付的文件**——程序檢核報告、全案報告、節點交付包、封存包，可列印或另存 PDF。

### 1.2 重要邊界

- **工具不替代法律專業判斷。** 它提醒你「這個期限到了」，不告訴你「這個案件該怎麼認定」。
- **工具不會主動通知你。** 沒有排程提醒、沒有系統通知、沒有電子郵件。提醒只在你開啟工具時顯示，請搭配公務行事曆或校內流程使用。
- **完全離線、單機、單人。** 不連網、不上傳、不收集任何資料。所有資料只存在你指定的工作區資料夾。
- **只支援 Windows 電腦與 A4 紙本作業。** 沒有手機版、平板版，也沒有多人協作或雲端同步。

### 1.3 誰在用

主要使用者是**學校性平業務承辦人**。若學校有主秘統籌多位承辦人的進度，主秘可另外使用「主秘統整中心」彙整（見第 11 章）。

## 2. 開始使用

### 2.1 首次啟動

第一次開啟工具時會依序出現：

1. **授權條款**——必須閱讀並同意才能繼續。版號更新後會要求重新確認。
2. **資料儲存注意事項**——說明資料存放位置與雲端同步的風險。必須勾選確認才能開始使用。
3. **歡迎導覽**（三頁）——介紹工具能做什麼、資料只在本機、常用快捷鍵。之後可從「介面 → 功能說明」重看。

### 2.2 建立工作區

工具的所有資料都放在一個「工作區」資料夾裡。首次啟動會要求你指定位置。

- **建立新工作區**：只能選擇**完全空白的資料夾**。如果路徑已有任何檔案，工具不會刪除或覆寫，會請你改選其他位置。
- **開啟既有工作區**：選擇之前建立過的工作區資料夾。

**存放位置建議**：

- 放在固定電腦的本機磁碟（例如 `D:\性平工具\`）。
- **避免**放在 OneDrive、Google Drive、iCloud 等同步資料夾。工具本身不上傳資料，但同步軟體仍可能把案件資料與附件上傳到雲端。
- 定期建立完整工作區備份，保存於受控的離線儲存裝置。

### 2.3 設備授權

工具採一機一授權：

1. 開啟工具後，複製畫面上的**申請碼**（這段碼**不含任何案件資料**）。
2. 把申請碼寄給作者索取認證碼。
3. 收到認證碼後貼回工具完成啟用。

**未授權時的限制**：只有「新增案件」被擋住。既有案件仍可正常讀取、編輯、回報節點、結案、匯出與備份。

以下操作都算「新增案件」，未授權時同樣會被擋：

- 從通報追蹤一鍵開案
- 匯入案件或完整遷移包
- 主秘統整帶入本機沒有的新案件

**換電腦、重灌或更換主機板後需重新索取**，回覆不保證即時，請預留時間。

### 2.3.1 試用序號

想先實際走一遍流程再決定的人，可以在同一個「輸入認證碼」的欄位改填**試用序號**
`CHASHAO-TRIAL-ONECASE`（不分大小寫）。輸入後會先跳出一次說明，勾選確認才會啟用。

試用的範圍與限制：

- **只能建立 1 件案件**。把案件刪掉重建不會回復額度。
- **輸入正式認證碼時，試用期間建立的那件案件會被完全清除，且無法復原。**
  程式會在寫入認證碼「之前」再警告一次，屆時可以先取消、匯出或備份，再回來輸入。
- 試用期間其他功能不受限制，可以正常填節點、產文件、匯出與備份。
- 額度用完後既有案件仍可讀取、編輯、結案、匯出與備份，只有新增案件被擋。

**請不要把真實案件資料填進試用案件**——它遲早會被清除。

試用紀錄存放在**應用程式資料夾**（與授權檔同一處），不在工作區裡。因此刪除工作區、
重建工作區、刪掉資料檔重新開啟，都不會讓試用額度回復。本工具不會為此寫登錄檔、
藏檔案或連網驗證；把應用程式資料夾整個刪掉確實可以重新試用，這是刻意保留的界線。

### 2.4 切換工作區

從「更多功能 → Tauri 工作區設定」可切換到其他工作區。

切換前工具會確認資料都已寫入。若事件表單還有未儲存的內容，工具會先阻止切換，請先按「儲存」或「取消」。

## 3. 介面總覽

### 3.1 三個主要工作區

畫面左上有三個並列的主工作區，點擊切換：

| 工作區       | 用途                                     |
| ------------ | ---------------------------------------- |
| **案件管理** | 性平案件的完整程序追蹤（最主要的工作區） |
| **通報追蹤** | 尚未正式開案的通報事件紀錄               |
| **日常業務** | 學期行事曆、日常任務、委員會議、年度報告 |

### 3.2 左側邊欄

由上而下：

- **品牌區**：點擊 Logo 或版號可開啟「關於叉燒」。
- **狀態列**（三條）：
  - **完全離線**——固定顯示，提醒不連網、不上傳。
  - **儲存狀態**——顯示「尚未變更／儲存中／已自動儲存 時間／儲存失敗」。
  - **備份狀態**——顯示上次匯出時間；從未備份時會顯示警告，點擊可直接進入備份流程。
- **工作區切換**、**搜尋框**、**篩選器**、**案件清單**。

### 3.3 案件總覽

進入「案件管理」預設看到總覽，包含：

- **四個統計數字**：案件總數、法定逾期、期限提醒、事件紀錄。
- **案件清單**：顯示案件編號、學校、狀態、下一個期限。

### 3.4 篩選與搜尋

搜尋框可依**案件編號、學校、承辦人、當事人姓名或代號**查找。

篩選條件包含：

- **案件類型**
- **案件狀態**
- **期限狀態**：全部／有逾期／期限接近／無待辦期限
- **申復狀態**：全部／尚有未結申復／申復全部已結
- **是否包含已封存案件**
- **排序方式**

### 3.5 鍵盤快捷鍵

| 按鍵 | 功能                       |
| ---- | -------------------------- |
| `N`  | 建立案件                   |
| `E`  | 回報程序節點（需先選案件） |
| `/`  | 聚焦搜尋框                 |
| `1`  | 切換到案件總覽             |
| `2`  | 切換到案件詳情             |
| `?`  | 顯示快捷鍵說明             |

隨時可從「介面 → 鍵盤快捷鍵」重看。

### 3.6 彈出視窗的操作規則

**所有彈出視窗都不能用點擊外側或按 Escape 關閉。** 必須使用視窗內的「取消」、「關閉」、「確認」或「儲存」按鈕。

這是刻意的設計，避免你在填寫到一半時誤觸而讓輸入消失。

## 4. 案件管理工作區

### 4.1 建立案件

按「建立案件」或快捷鍵 `N`，以三段式流程完成：

**第一段：基本資料**

- 案件編號、學校、承辦人
- 案件類別與類型（校園性別事件／性騷擾、性侵害、性霸凌、違反專業倫理等）
- 知悉日期——**這是多數法定期限的起算基準，務必正確填寫**

**第二段：當事人**

- 逐一新增當事人，填寫代號、姓名、身分（學生／教職員）、角色（被害人／行為人／檢舉人等）。
- **成年狀態**必須選擇「未確認／成年／未成年」。未成年必填年齡，成年可不填。
- 學生可標示是否為特殊教育學生。

**第三段：確認建立**

建立後，工具會依你填的資料**自動建立該案應有的程序節點**。例如：

- 有未成年被害人或屬性侵害案件 → 出現社政通報期限
- 行為人為教職員 → 出現移送教評會與教師暫時停聘的節點
- 行為人或被害人為教職員 → 調查小組出現「全部校外委員」要求
- 當事人含特殊教育學生 → 調查小組出現「特殊教育專長委員」要求

### 4.2 當事人管理

從「更多 → 當事人管理」進入，可隨時增修當事人。

**注意事項**：

- **同一案件不得使用重複的當事人代號。** 同名的人不會被自動視為同一人，請自行確認。
- 若填寫的年齡與成年狀態標示衝突（例如年齡 16 但標示為成年），工具會提示，但不會自動改。
- 當事人代號會即時反映到時間軸與各項輸出。

### 4.3 案件工作台的三種時間軸

案件詳情有三個並列頁籤：

| 頁籤                   | 內容                                     |
| ---------------------- | ---------------------------------------- |
| **案件法定程序時間軸** | 法定程序節點與期限，這是主要的工作畫面   |
| **案件大事紀時間軸**   | 事實整理層，記錄事件經過，不納入法定程序 |
| **案件完整時間軸**     | 前兩者合併呈現，看整體脈絡               |

### 4.4 回報程序節點

在法定程序時間軸點擊節點，或按快捷鍵 `E`。

每個節點可登錄：

- **發生日期**——填了才算完成
- **標題與說明**
- **必要文件**——各節點有固定的必要文件清單，未附齊會顯示缺件提醒。確實無法提供時，可填寫免附理由抵免。
- **附件**——支援 PDF、Word（DOC／DOCX）、圖片、音訊。工具不提供 Word 內建預覽，請用電腦上已安裝的文書軟體開啟。
- **送達紀錄**——登錄通知送給誰、何時送達。這會直接影響申復期限的起算。

**重要規則**：

- **完成「受理通知」或「處理結果通知」前，必須逐一登錄相關當事人的送達資料。**
- **附件按「取消」時，只會清除本次新增的檔案**，不會刪掉先前已存在的附件。
- 節點的說明性提示會告訴你這個節點的意義與注意事項。

### 4.5 調查路徑與簡化調查程序

案件工具列有「調查路徑」，可選擇：

- **待決定**
- **調查小組**——一般路徑
- **簡化調查程序**——符合條件時的簡化路徑
- **其他調查方式**

**進入簡化程序前必須逐項確認**：

1. 案件已受理
2. 行為人均為學生
3. 資料已足夠
4. 無訪談必要
5. 無組成調查小組的要求

**進入後**可分別保存每位當事人的原始陳述、問答、補充與附件引用，再建立不可變的報告版本，並記錄審議結果與退回補正。

**何時必須轉回調查小組**：出現組成調查小組的要求、資料不足、新事證、申復或重新調查、行為人非學生。此時工具會阻止你完成簡化報告，要求走「轉回調查小組」流程。

轉換後，既有內容變成唯讀歷史，原期限不重算。審議通過時會同步建立主案件的調查完成日期，讓後續議處與通知期限正常出現。

可輸出 A4 或 DOCX 的完整程序紀錄。

### 4.6 訪談時程安排

從案件工具列進入「訪談時程安排」，可規劃訪談場次、受訪對象與時間。

「調查小組組成」與「調查小組會議／訪談」是分開的兩件事：

- **組成節點**只登錄成員與組成檢核（性別比例、校外委員比例、特教專長等）。
- **會議／訪談節點**才登錄會議次別、受訪對象與本次出席委員。

### 4.7 案件大事紀

大事紀是**事實整理層**，用來梳理事件經過，與法定程序節點平行，不會併入行政程序。

**每筆大事紀可記錄**：

- 日期（可設定精確度）與標題
- 分類（可用常用分類模板）
- 相關當事人與外部人員
- **多方說法**——分別記錄當事人、證人、文件或其他來源的說法
- 確認狀態與人工注意提醒
- 附件佐證

**檢視方式**：可切換時間軸式清單或表格檢視，支援關鍵字、當事人、分類、確認狀態篩選。

**插入點**：在法定程序時間軸可新增「大事紀插入點」，錨定在某個程序節點的前或後。全案報告產生時，會在該位置插入大事紀章節。插入點可設定引用全部大事紀、依條件引用（日期區間、分類、當事人）或指定特定項目。

**遮蔽版輸出**：可輸出原版或遮蔽版。遮蔽版依當事人代號替換姓名，並保留人工覆核提醒——**請務必人工覆核後再對外提供**。

### 4.8 資料夾索引

從「更多 → 資料夾索引」進入。

用途是把**工具外部**的檔案（例如你自己整理在其他資料夾的文件）建立索引並關聯到案件節點，不必把檔案複製進工具。索引只記錄位置，不保存檔案內容。

### 4.9 案件費用統計

從「更多 → 案件費用統計」進入。

**可記錄兩類費用**：調查小組出席費、調查報告出席費。

**操作方式**：

1. 先設定本案適用的學校收費規定與預設單價。
2. 逐筆輸入日期、受款／出席人、項目、數量、單位、單價與備註。
3. 工具自動計算分類小計與本案實際成本。

**注意**：

- 費用資料隨案件保存，不會因日後修改其他案件而回溯變動。
- 可輸出 A4 列印／另存 PDF 的**內部**費用明細。
- **費用不會自動併入對外報告、附件 ZIP 或當事人交付資料。**
- 此功能只做兩類實際成本統計，**不推定法定金額**，也不處理付款、核銷、憑證、所得、交通或住宿費。

### 4.10 結案與封存

從「更多 → 結案／封存」進入。

工具會先檢查程序是否走完。**程序未走完時不會顯示結案或封存完成。**

封存包可產生整案 ZIP，內容固定為：

- 案件資料
- 說明檔
- 所有可讀取的附件原檔
- 交付與附件清冊
- 有資料時才產生的外部索引清冊與缺件提醒

**封存 ZIP 不包含節點報告 PDF。** 報告請另用「全案報告」產生。

結案後仍可修改，但會留下紀錄。

## 5. 期限管理

這是工具的核心。

### 5.1 法定死線與校內時程

工具同時管理兩種期限：

- **法定死線**——法規規定的期限，逾期有法律效果。
- **校內時程**——學校自訂的提前控管目標，只用於提早提醒。

兩者在案件期限卡片、總覽、排序、程序檢核與報告中**分別顯示**。校內目標逾期只會顯示提醒，**不會被誤標成法定逾期**。

### 5.2 期限規則設定

從「更多功能 → 期限規則設定」進入。

**修改法定死線時**：

1. 必須填寫修改原因與確認依據。
2. 儲存前工具會顯示規則差異、受影響的案件、可能新增或解除的逾期狀態。
3. 需要再次確認才會生效。

**設定校內時程時**：校內時程可以早於或等於法定死線，但**不得晚於**法定死線；不符合時會直接阻擋儲存。

### 5.3 期限如何計算

工具依法規計算，主要原則：

- **始日不算入**，自次日起算。
- 以「月」計算的期限，末日為相當日之前一日。
- 到期月份沒有相當日時（例如 1 月底知悉、一個月期限落在 2 月），末日取該月最後一日。
- **末日遇假日順延**至下一個工作日。

法源依據與逐條對照見 `性平案件法定期限說明.md`。

### 5.4 年度辦公日曆

期限的假日順延依賴正確的年度辦公日曆。從「更多功能 → 年度辦公日曆」進入。

- 工具**內建 2025、2026 年**政府行政機關辦公日曆的例外日。
- **2027 年起需自行維護**：工具提供一段提示詞，你可複製後請外部 AI 依政府公告的辦公日曆整理成指定格式，再回到工具匯入。
- 匯入前工具會顯示來源、放假／補班筆數、與同年度既有資料的差異，以及對現有案件期限的影響。**需人工核對並再次確認後才會整批寫入。**
- 平日放假會延後期限末日，週末補班會恢復為工作日。
- 也可手動新增單一日期。

**提醒**：當案件期限已涉及尚未匯入的年度時，工具會在啟動時提示一次。未匯入該年度前，期限計算只套用一般週末與既有手動日期。

### 5.5 期限延長

部分期限可依法延長（例如調查完成期限可延長，每次一個月、最多兩次）。

在期限節點可登錄延長紀錄，工具會重新計算到期日。特殊延長狀態會在期限卡片上標示。

### 5.6 提醒門檻設定

從「更多功能 → 提醒門檻設定」進入，可調整：

- 以小時計的期限，剩幾小時算「緊急」
- 以日計的期限，剩幾天算「即將到期」

調整後會立即反映到所有案件的期限狀態顏色。

### 5.7 提醒的邊界

**工具不會主動通知你。** 沒有排程提醒、系統通知或電子郵件。

所有提醒只在你**開啟工具時**顯示。請搭配公務行事曆或校內流程使用。

## 10. 模板與文稿中心

從「更多功能 → 文書範本」進入。畫面分三區：

- **左側**：管理外部交換與統一治理目錄。
- **中間**：編輯目前的節點文字模板。
- **右側**：處理不可變版本、發布、案件文稿快照、覆核與正式 DOCX。

### 10.1 AI 只作外部模板助手

- 工具可下載**不含任何案件資料**的規範包。
- 你可把規範包提供給外部 AI，請它產生模板，再把結果匯入工具。
- **工具不會自動上傳案件或公文。**
- **AI 回傳的內容只能成為草稿，不能直接發布。**

### 10.2 模板治理

- 正式模板只能由主秘確認發布。
- **已發布的版本不可原地覆寫**，只能建立新版本。

### 10.3 文稿快照與覆核

- 正式文稿只能使用已發布的模板。
- 文稿會保存產生當時的案件資料與模板版本，日後案件資料異動不會回頭改寫已產生的文稿。
- 含有未填標記的文稿**可以送覆核，但不得核定**。補齊資料後可建立下一版，舊版不被改寫。

### 10.4 DOCX 輸出

已核定的文稿可輸出真正的 Office 格式檔案，支援 A4、頁首頁尾、頁碼、表格、清單、簽章欄與分頁。

匯入既有 DOCX 前，工具會檢查巨集、外部連結與嵌入物件；通過後只能建立草稿。

## 11. 主秘統整中心

從「更多功能 → 主秘統整中心」進入。此功能供**主秘統籌多位承辦人進度**時使用。

### 11.1 承辦人端

在承辦人的工作區建立「彙整包」，內含管理資料快照與獨立序號。

**彙整包不含案件附件、日常任務附件或文稿正文。**

### 11.2 主秘端

1. 一次選取多位承辦人的資料包。
2. **預檢**——檢查來源、序號、版本是否正確。
3. 產生**方案**——顯示會做哪些變更，此時尚未寫入。
4. 逐項處理衝突。
5. 提交。

### 11.3 來源判定不靠檔名

每個來源工作區有自己的穩定識別與序號。**重複、舊版、缺版、分叉與未登錄的來源會分開顯示**，檔案選取順序與電腦時間不影響判定。

### 11.4 衝突處理

以下情形都需要明確決定並填寫理由：

- 主秘曾修改過同一筆資料
- 不同來源主張同一筆資料的所有權
- 同案號但識別不同
- 刪除與缺版

**沒有來源追溯或刪除基準不符的外來刪除只能略過**，不能刪除主工作區的資料。

成功套用後，可追溯到來源承辦人、工作區、資料包、序號與主秘的決定。

### 11.5 共同領域專案

不同來源的分支可彙整成同一專案，包含任務、里程碑、進度與排序。斷裂的依賴、缺少的附件或刪除引用會阻止套用。

### 11.6 安全機制

- **套用前會自動建立完整工作區備份。**
- 提交採全有全無：規劃後資料已改變或提交失敗時，不會破壞原工作區。

詳細規範見 `主秘統整中心_操作與技術規範.md`。

## 12. 備份、還原與資料安全

### 12.1 三種備份用途完全不同

| 類型               | 內容                                           | 用途                             |
| ------------------ | ---------------------------------------------- | -------------------------------- |
| **資料 JSON**      | 案件、日常資料與附件中繼資料，**不含附件原檔** | 檢視與資料交換                   |
| **SQLite 快照**    | 只有資料庫與附件索引                           | 緊急診斷，**程式不提供直接還原** |
| **完整工作區備份** | 全部資料、附件原檔、刪除歷程、稽核紀錄等       | **正式的災難復原格式**           |

備份中心會逐項列出各類型的涵蓋範圍。**只有第三種才是真正能救回全部資料的備份。**

### 12.2 建立完整工作區備份

從「更多功能 → 備份中心」進入，可直接選擇外部目的資料夾。

- 建立期間會**暫停其他工作區操作**。
- 複製資料、刪除歷程、全部附件索引與原檔、稽核紀錄及行事曆匯入歷程。
- 建立筆數、容量與檢查碼清單。
- 暫存成品必須**先通過還原預檢**才會顯示為完成。缺檔、內容不符或有孤兒附件都會阻擋——**不會留下看似成功、實際不完整的備份**。

**重要**：完整備份**未加密**，請保存於受控的磁碟或離線裝置。

### 12.3 還原

還原前工具會驗證版本、完成標記、逐檔檢查碼、筆數、關聯、檔案集合與所需磁碟空間。

- 通過驗證並經你明確確認後才會重建。
- **損壞的備份不會改動目前的工作區。**
- **還原是整個工作區取代，不做隱性合併。**
- 成功後立即重新載入，不必關閉重開。

### 12.4 匯出與匯入

- **匯出本案 JSON**／**匯出本案完整遷移包**——單一案件。
- **匯出全部資料 JSON**——整個工作區的資料（不含附件原檔）。
- **匯出完整遷移包**——含附件的完整內容。

匯入完整遷移包前會做無副作用預檢：壞檔、版本不符、資料關聯錯誤、缺附件或空間不足都會在寫入前拒絕，且**拒絕時不會改動現有資料**。

### 12.5 刪除的不可逆性

**目前版本中，刪除案件、節點、當事人等資料無法在工具內復原。**

所有刪除都需要二次確認（勾選確認，部分需輸入指定文字）。刪除後只能從先前的備份重新匯入整個工作區。

**請務必在刪除前確認已有完整備份。**

### 12.6 關閉工具

關閉視窗時，工具會先確認資料都已寫入才允許關閉。若寫入尚未完成或失敗，視窗會保持開啟並顯示原因。

## 13. 資料健康檢查

集中列出工作區中的資料問題，包含：

- **附件原檔遺失**——索引中有紀錄但檔案找不到
- **孤兒附件**——檔案存在但沒有任何紀錄引用
- **當事人年齡與成年狀態衝突**
- **大事紀遮蔽版可能缺少當事人代號**
- **日常任務附件原檔遺失**
- **尚未匯出備份的提醒**
- 其他資料一致性問題

每項問題可直接跳到對應的案件與節點處理。也可匯出問題清單（CSV）供離線整理。

**遺失的附件可重新上傳補齊；孤兒附件可批次清理。**

## 15. 建議操作順序

### 15.1 第一次使用

1. 同意授權條款，確認資料儲存注意事項。
2. 建立工作區（選擇本機固定磁碟的空白資料夾）。
3. 完成設備授權。
4. 匯入或確認**年度辦公日曆**——這會影響所有期限計算。
5. 建立**性平專家人才庫**與**性平委員資料庫**（可先略過，需要時再建）。
6. 依需要調整**期限規則設定**與**提醒門檻設定**。

### 15.2 新案件的標準流程

1. **建立案件**——正確填寫知悉日期與當事人資料（含成年狀態、身分、角色）。
2. 檢視工具自動建立的**程序節點與期限**，確認是否符合本案實際情形。
3. 依實際進度**逐一回報節點**，附上必要文件、登錄送達紀錄。
4. 需要時使用**大事紀**整理事實經過。
5. 決定**調查路徑**（調查小組或簡化程序）。
6. 產生**程序檢核報告**確認沒有遺漏。
7. 結案前確認程序走完，再進行**結案／封存**。

### 15.3 每日／每週建議

- **開啟工具時先看總覽的四個統計數字**，特別是「法定逾期」與「期限提醒」。
- 逐案確認接近到期的節點。
- **定期匯出備份**——狀態列會顯示上次備份時間，從未備份時會警告。

### 15.4 定期維護

| 頻率     | 事項                                                   |
| -------- | ------------------------------------------------------ |
| 每週     | 建立資料 JSON 匯出                                     |
| 每月     | 建立**完整工作區備份**並保存於離線裝置                 |
| 每學期   | 執行**資料健康檢查**，處理遺失附件與資料衝突           |
| 每年底前 | 匯入**次年度辦公日曆**（工具會在期限涉及該年度時提示） |

## 附錄：常見問題

**Q：工具會提醒我期限到了嗎？**
不會主動提醒。所有提醒只在開啟工具時顯示。請搭配公務行事曆使用。

**Q：可以多人同時使用同一個工作區嗎？**
不行。工具設計為單人單機使用。若需彙整多位承辦人的進度，請使用主秘統整中心。

**Q：資料會上傳嗎？**
不會。工具完全離線，不發送任何網路請求。但若工作區放在雲端同步資料夾，同步軟體仍可能上傳，請避免。

**Q：刪錯了可以還原嗎？**
目前版本不行，只能從備份重新匯入整個工作區。刪除復原功能已列入 2.0.0 規劃。

**Q：換電腦怎麼辦？**
建立完整工作區備份，在新電腦還原，並重新索取設備授權碼。

**Q：期限算錯了怎麼辦？**
先確認年度辦公日曆是否已匯入該年度。若確定是規則問題，可在「期限規則設定」調整，但需填寫原因與依據。

**Q：報告可以直接存成 PDF 嗎？**
按「列印／另存 PDF」會叫出瀏覽器的列印視窗，在印表機選擇「另存為 PDF」即可。
