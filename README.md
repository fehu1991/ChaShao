# 叉燒 ChaShao

叉燒 ChaShao 是為校園性平業務承辦人設計的 Windows 桌面工具。它以固定辦公電腦、完全離線、單機、單人使用為前提，把通報追蹤、案件程序、法定期限、當事人、附件、日常業務與文件交付整理在同一個本機工作區。

工具本身不主動連網、不上傳資料，也不使用雲端同步。資料與附件會保存於使用者指定的工作區，實際電腦、帳號、磁碟與備份媒體的安全管理，仍由使用單位依校內規範負責。

## 主要功能

### 通報追蹤

記錄已知悉、已完成通報但尚未正式開案的疑似事件，包含知悉時間、校安與社政通報、事件摘要、相關人員及後續追蹤。列表可切換全部、追蹤中、已開案與已結束，也能唯讀檢視或一鍵帶入案件建立流程。

### 案件工作台

以案件總覽集中查看今日、本週、本月、逾期與全部待辦。案件內提供三步驟建案、關鍵日期、當事人代號、法定程序時間軸、案件大事紀、完整時間軸、附件與文件檢核、申復、調查路徑、訪談時程、報告產出、費用統計、承辦人歷程與結案封存。

程序節點會依承辦人回報的結果建立後續分支；需要人工判斷的項目會明確標示，不把工具計算結果當成法律或事實決定。申請調查、一般檢舉、性平會檢舉與公益檢舉均須填寫案件申請書，並在「收件／收到案件申請書」節點記錄實際收件日及上傳文件。

### 日常業務管理

以學期、寒暑假與校務行事曆管理例行工作，支援任務模板、期限、檢核項目、附件、性平會議、宣導活動、委員資料與學期／年度報告。案件期限與日常工作可以在同一套工作區內交叉查看。

### 其他性平業務

提供性平專家人才庫、性平委員資料庫、案件費用統計、文件模板與文稿管理，以及學校名稱與 Logo 設定。正式輸出文件可帶入學校識別，案件資料則依當時狀態保存快照，避免後續名單變更改寫歷史紀錄。
